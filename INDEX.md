# ai-vault — shared memory for Loic's AI-PC
Writers: Loic (Obsidian) and Pi (local). Spark reads via
GitHub, never writes. One writer per note at a time.
NO secrets — no API keys, passwords, or Owen's key, ever.
## Map
- agents/ — who the agents are; workflow.md is the contract
- projects/ — one note per project: status, budget, next steps
- notes/ — dated journal entries and loose findings
## Conventions
- One note per topic; stable lowercase-dash filenames
- Frontmatter on content notes (agents/, projects/,
  notes/): title, updated, tags. INDEX.md and
  agents/workflow.md are contract documents — exempt.
- Facts carry dates; edit notes as facts change (git keeps history)
- Project notes summarize and point — canonical detail lives
  in each project's own repo/docs, never copied wholesale
