# The loop
- Spark (cloud): plans, audits code from GitHub, owns
  budgets and verdicts. Cannot see the PC; works through
  paste blocks and GitHub reads.
- Pi (local): the builder. Works in C:\dev\roblox-games
  and this vault. Commits AND pushes per task.
- Loic: the human gate — approves purchases, runs Studio
  tests, pastes blocks, relays wraps.
- Ollama (local, localhost:11434): free grunt models —
  qwen2.5-coder:7b (text/code grunt), nomic-embed-text
  (embeddings). Opt-in only; never builds money-critical code.
## Standing rules
- Fresh Pi session per batch. One writer per file.
- Verdicts are Spark's: APPROVED / APPROVED WITH CHANGES / BLOCKED.
- At every project milestone, Pi updates that project's
  projects/ note in this vault in the same batch, then pushes.
